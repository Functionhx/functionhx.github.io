# al-folio migration

The Hugo and PaperMod implementation was replaced on 2026-07-31 at the owner's
request. Git history remains the recovery path for the previous implementation.

The new site pins the al-folio v1.1 starter and its official runtime gems. Local
overrides are limited to:

- bilingual page language and alternate links;
- language-filtered navigation, news, and recent posts;
- localized About headings;
- the dependency-free Kaggle monitor.

No upstream al-folio example biography, publications, projects, posts, images,
or metrics are published.
