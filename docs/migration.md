# al-folio migration

The Hugo and PaperMod implementation was replaced on 2026-07-31 at the owner's
request. Git history remains the recovery path for the previous implementation.

The site pins the al-folio v1.1 starter and its official runtime gems. Its
information architecture and visual density follow that release:

- original-order About, blog, publications, projects, repositories, CV,
  teaching, people, and submenu navigation;
- original profile, project, publication, blog, course, book, and CV demo
  structures;
- bilingual routes, language-filtered collections, and alternate links;
- light and dark themes plus desktop and mobile layouts;
- the dependency-free Kaggle monitor.

Verified owner content replaces an upstream sample whenever it is available.
Public pages present the original theme directly, without editorial migration
notes mixed into the site copy.
