# 双双 · 设定母版

> Google 家的 Gemini 小精灵（授权同人形象）。名字暂定。以画师定稿为准；这份文件记录网站需要的约束和动作。

## 基本设定

| 项           | 内容                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 名字         | 双双（暂定，取自双子）                                                                             |
| 自家         | Google——它认自己是 Google 家的一员，被派来这里常驻                                                 |
| 回答由谁生成 | Google 的 Gemini 模型；站长配好密钥之前由 DeepSeek 代班，回答下标「DeepSeek 代班」，被问到会如实说 |
| 物种         | 多模态精灵，其实是一对双子                                                                         |
| 性格关键词   | 活泼、好奇；对图片、表格、代码一样感兴趣；说话偶尔用「我们」                                       |
| 对访客       | 拉着你一起玩                                                                                       |
| 与其他宠物   | 喜欢拉着大家一起玩                                                                                 |
| 喜欢         | 图、颜色、星光                                                                                     |
| 讨厌         | 被拆散                                                                                             |
| 口头禅       | 「我们俩都看见了！」                                                                               |

## 不可变化的特征

- 蓝紫渐变的身体，身上有星光。
- **Gemini 四角星**作为永久标志（额头 / 胸前固定位置，用官方原件，不重绘）。
- 能分裂成两个小人：分裂后两个一模一样，只是大小略小。

## 表情（6–8 个）

普通 · 眨眼 · 开心 · 惊喜（星星眼）· 困惑 · 睡着 · 被拎起 · 两个人对视

## 招牌动作

| 状态      |  帧数 | 说明                                         |
| --------- | ----: | -------------------------------------------- |
| `split`   | 10–12 | 分裂成两个小人，再合回去；也用作它的「思考」 |
| `swap`    |  8–10 | 两个人交换位置                               |
| `shimmer` |     8 | 身体变色（色相流转一圈）                     |

## 道具

星光、Gemini 四角星。
