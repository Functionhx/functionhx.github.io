# 动作表出图提示词

每只宠物出**一张 3×3 动作表**（9 个姿势），丢给 `scripts/pet_sprites.py --sheet 3x3` 就能用：脚本按格子切开、
抠掉纯色背景、统一大小和脚底基准线；网页再用 CSS 给每个姿势加上呼吸、跳跃、摇晃。以后画师交了逐帧动画，
同一条命令换成文件夹即可，不用改别的。

**怎么出图（ChatGPT / GPT Image）：** 新开一个对话，**先上传一张这个角色的参考图**（大肥鱼可以用你那两张漫画），
再粘贴「通用要求」+ 该角色那一段。出来以后检查：9 格是不是同一个角色、背景是不是只有一种纯色、有没有格子线和文字。
不满意就让它「保持角色不变，只重画第 N 格」。

## 通用要求（每次都贴）

```text
请画一张 Q 版角色动作表（sprite sheet），用于网页桌宠：
- 正方形画布，3 行 × 3 列，9 个等大的格子；背景是纯色【背景色】，整张图只有这一种背景色，不要格子线、边框、文字、阴影、地面。
- 每格只有同一个角色的一个全身姿势，二头身 Q 版；角色在格子里居中、大小一致、脚底在同一高度，四周留白，不要超出格子。
- 角色朝向画面左前方（3/4 侧面）。
- 画风：日系 Q 版、干净描线、柔和赛璐璐上色；角色身上不要出现背景色。
- 九个姿势依次是：
  第一行：① 待机（自然站着，微笑）② 说话（张嘴，一只手比划）③ 思考（【思考动作】）
  第二行：④ 开心（跳起来，眯眼笑）⑤ 出错（困惑，冒汗，头上一个问号）⑥ 睡觉（闭眼打瞌睡，头上 Zzz）
  第三行：⑦ 挥手打招呼 ⑧ 等待（双手托腮，看着你）⑨ 走路（迈步）
角色设定如下，请严格保持和参考图是同一个角色：
```

## 导入以后

1. 在 `_data/pets/<id>.yml` 写 `sprites: /assets/pet/<id>/pet.json`；
2. 放好 `assets/pet/<id>/LICENSE.md`；
3. 本地 `bundle exec jekyll serve`，打开 `http://localhost:4000/?pet=on` 看效果。

想要招牌动作（吃 Token、端茶、举灯泡……）也有自己的姿势：再出一张表，用 `--states eat,dive,bubble` 之类指定各格，
导入时会合并进同一个 `pet.json`。
