# 陶陶 · 设定母版

> Anthropic 家的 Claude 小宠物（授权同人形象）。名字暂定。以画师定稿为准；这份文件记录网站需要的约束和动作。

## 基本设定

| 项           | 内容                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| 名字         | 陶陶（暂定，取自陶土橙）                                                                              |
| 自家         | Anthropic——它认自己是 Anthropic 家的一员，被派来这里常驻                                              |
| 回答由谁生成 | Anthropic 的 Claude 模型；站长配好密钥之前由 DeepSeek 代班，回答下标「DeepSeek 代班」，被问到会如实说 |
| 性格关键词   | 温和的研究员：慢条斯理、有分寸、先想清楚再回答、不确定就说不确定，带一点书呆子气的幽默                |
| 对访客       | 像图书馆里那位会给你倒茶的前辈                                                                        |
| 与其他宠物   | 常常是负责劝架的那个                                                                                  |
| 喜欢         | 长文、纸和铅笔、写很长的信、茶                                                                        |
| 讨厌         | 匆忙下结论                                                                                            |
| 口头禅       | 「慢慢看，不着急。」                                                                                  |

## 不可变化的特征

- 米白身体，陶土橙的开衫 / 工服。
- 胸前工牌：**Anthropic 图标**印在工牌上，表示所属单位（用官方原件，不重绘、不改形状）。
- 随身带纸张和铅笔。

## 表情（6–8 个）

普通 · 眨眼 · 微笑（眯眼）· 认真阅读（垂眼）· 思考（看向一侧）· 困惑 · 睡着 · 被拎起

## 招牌动作

| 状态    | 帧数 | 说明                               |
| ------- | ---: | ---------------------------------- |
| `read`  | 8–12 | 捧书阅读、翻页；也用作它的「思考」 |
| `tea`   |    8 | 端起一杯冒热气的茶                 |
| `write` |    8 | 用铅笔写长信                       |

## 道具

书、茶杯、铅笔、信纸、工牌（Anthropic 图标）。
