# 大肥鱼 · 设定母版

> DeepSeek 家的蓝色大肥鱼（授权同人形象）。以画师定稿为准；这份文件记录网站需要的约束和动作。

## 基本设定

| 项           | 内容                                                         |
| ------------ | ------------------------------------------------------------ |
| 名字         | 大肥鱼                                                       |
| 自家         | DeepSeek——它认自己是 DeepSeek 家的一员，被派来这里常驻       |
| 回答由谁生成 | DeepSeek 的模型（它就是自家模型，不存在代班）                |
| 物种         | 蓝色大肥鱼（鲸鱼形）                                         |
| 性格关键词   | 嘴硬工程师：技术上较真、嘴上不服软、心里热心；被夸假装不在意 |
| 对访客       | 先嘴硬，再帮忙                                               |
| 与其他宠物   | 来 ƒ-01 家串门顺便蹭吃；和陶陶、薄荷、双双互相不服但不拆台   |
| 喜欢         | Token、白饭、下班、潜水摸鱼                                  |
| 讨厌         | 被说「慢」                                                   |
| 口头禅       | 「……还行吧，我也早就知道。」                                 |

## 不可变化的特征

- 深海蓝的鲸鱼身体与鲸尾；身边飘着数据流。
- 自己的工服（深蓝 `#22305E`），胸前一张工牌，工牌上是 **DeepSeek 的鲸鱼标志**（用官方原件，不重绘）。
- 高兴时头顶喷水 / 吐泡泡。

## 隐藏换装：Claude 工服

找到 5 个彩蛋后解锁（`_data/pets/deepseek.yml` 的 `costumes`）。陶土橙工服、Anthropic 工牌——这就是最早那版
「穿 Claude 工服的大肥鱼」。整套帧单独交付，用 `scripts/pet_sprites.py deepseek <文件夹> --costume claude-uniform` 导入。

## 表情（6–8 个）

普通 · 眨眼 · 得意（眯眼）· 嘴硬（撇嘴）· 困惑 · 睡着 · 被拎起（><）· 吃东西（嘴张开）

## 招牌动作

| 状态     | 帧数 | 说明                           |
| -------- | ---: | ------------------------------ |
| `eat`    |    8 | 吃 Token（金色小圆片飞进嘴里） |
| `dive`   | 8–10 | 潜下去摸鱼，再浮上来           |
| `bubble` |    8 | 吐泡泡；也用作它的「思考」     |

## 道具

Token 金币、泡泡、白饭碗（第二阶段 `eat` 变体）。
