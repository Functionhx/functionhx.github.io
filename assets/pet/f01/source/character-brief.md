# ƒ-01 · 设定母版

> 本站原住民，也是默认出场的那只。原创角色，**不使用任何公司的标志**。
> 画师若已有定稿，以定稿为准，把下面与定稿不一致的地方改成定稿的样子——这份文件的作用是让每一帧都长得一样。

## 基本设定

| 项          | 内容                                                      |
| ----------- | --------------------------------------------------------- |
| 名字        | ƒ-01（访客可以给它起小名）                                |
| 物种        | 函数生命体：平时是圆滚滚的小型深海生物                    |
| 性别表达    | 不设定                                                    |
| 年龄感      | 幼年，刚长出来不久                                        |
| 性格关键词  | 好奇、不谄媚、安静、有点呆、会假装自己只是一段 JavaScript |
| 与站长      | 从站长的代码和文章里长出来的；了解站长，但不是站长        |
| 对访客      | 先害羞（只探出半个头），熟了以后会记得你读到哪            |
| 与其他宠物  | 房东。大肥鱼、陶陶、薄荷、双双是来串门的同事              |
| 喜欢        | 旧终端、机器人、彩蛋（每个彩蛋是它的一个零件）            |
| 讨厌 / 害怕 | 被快速滚动甩晕；资源加载失败（会以为是自己弄坏的）        |
| 口头禅      | 「……我只是一段普通的 JavaScript。」                       |
| 变形        | 思考时身体展开成蓝色数据流，想完重新坍缩成软乎乎的一团    |
| 隐藏形态    | 零件集齐（11 个彩蛋）后的「完整形态」——第二阶段再画       |

## 不可变化的特征

- 尾巴是一条 **ƒ(x) 曲线**（斜体 ƒ 的形状，中间一道横）。
- **左眼下方**有一个小小的青色 ƒ 记号。
- 瞳孔外有一圈**青色圆环**。
- 身体圆滚滚、比例约 1 : 0.8（宽 : 高），没有手臂，只有一对小鳍。
- 不穿制服、不挂工牌、不出现任何公司标志。

## 表情（6–8 个）

普通 · 眨眼 · 开心（眯眼）· 困惑（一只眼眯）· 睡着 · 被拎起（><）· 惊讶（O 嘴）· 认真（平嘴）

## 动作

第一阶段九个状态见 `assets/pet/README.md`。它自己的招牌动作：

| 状态     |  帧数 | 说明                                                                       |
| -------- | ----: | -------------------------------------------------------------------------- |
| `unfold` | 10–12 | 身体展开成数据流（0、1、ƒ、x、括号向上飘），再缩回原形。也用作它的「思考」 |
| `wave`   |   6–8 | 用小鳍挥手（打招呼时用）                                                   |

## 道具

无。它身上唯一的「标志」就是 ƒ。
