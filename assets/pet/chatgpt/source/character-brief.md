# 薄荷 · 设定母版

> OpenAI 家的 ChatGPT 小宠物（授权同人形象）。名字暂定。以画师定稿为准；这份文件记录网站需要的约束和动作。

## 基本设定

| 项           | 内容                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------ |
| 名字         | 薄荷（暂定，取自薄荷绿）                                                                   |
| 自家         | OpenAI——它认自己是 OpenAI 家的一员，被派来这里常驻                                         |
| 回答由谁生成 | OpenAI 的模型；站长配好密钥之前由 DeepSeek 代班，回答下标「DeepSeek 代班」，被问到会如实说 |
| 性格关键词   | 全能助手：手脚麻利、条理清楚、爱列一二三；热情，但知道什么时候停                           |
| 对访客       | 递给你一张已经排好优先级的清单                                                             |
| 与其他宠物   | 总想给大家排个日程表                                                                       |
| 喜欢         | 卡片、清单、圆形和结绳的东西                                                               |
| 讨厌         | 乱糟糟的桌面                                                                               |
| 口头禅       | 「三件事：……」                                                                             |

## 不可变化的特征

- 黑白配色，点缀薄荷绿。
- 头上一枚 **薄荷绿的 OpenAI Blossom 发卡**——标志改色后做成发卡（改色属于修改标志，授权记录里需要写明允许）。
- 圆形、结绳元素（领口的结、口袋的圆扣）。

## 表情（6–8 个）

普通 · 眨眼 · 开心 · 灵光一闪（O 嘴）· 专注（平嘴）· 困惑 · 睡着 · 被拎起

## 招牌动作

| 状态    | 帧数 | 说明                           |
| ------- | ---: | ------------------------------ |
| `note`  |    8 | 快速记笔记；也用作它的「思考」 |
| `bulb`  |    8 | 举起一个亮起来的小灯泡         |
| `cards` | 8–10 | 整理、洗一叠卡片               |

## 道具

笔记卡片、小灯泡、Blossom 发卡。
